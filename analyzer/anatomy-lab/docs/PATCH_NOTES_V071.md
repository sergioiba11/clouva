# Parche v0.7.1 — Lobe Vertical Lock

## Corrige
- pines demasiado altos sobre la oreja
- falso positivo de readiness en pines de lóbulos

## Regla nueva
- el pin debe quedar a <= 1.5 cm del objetivo vertical del lóbulo
- ambos lados deben quedar con una diferencia de altura <= 1.8 cm

## Resultado esperado
- si no cumple, readiness = false
- si cumple, readiness = true
